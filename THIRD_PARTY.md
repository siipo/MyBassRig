among the dependencies, and it propagates.

## Why AGPL-3.0

The binding constraint is JUCE. Its modules are dual-licensed under AGPLv3 and a
commercial licence; this project uses the free option, so the combined work must
be AGPLv3. `JUCE_DISPLAY_SPLASH_SCREEN=1` is set in `CMakeLists.txt` because the
free licence requires it.

GPL-3.0 code can be combined into an AGPL-3.0 work — GPLv3 section 13 permits
this explicitly — so the GPLv3 dependencies below are compatible.

If this ever needs to be closed-source or commercially licensed, JUCE needs a
paid licence **and** every GPLv3 item below has to be replaced. The BSD-3 items
would be fine either way.

## Adapted code

`Source/dsp/ToneStack.h` contains the component network and the six-port R-type
scattering matrix for the Baxandall tone stack, adapted from the **BaxandallEQ**
example in [jatinchowdhury18/WaveDigitalFilters](https://github.com/jatinchowdhury18/WaveDigitalFilters)
(**GPL-3.0**), itself an implementation of Werner et al.

That matrix was generated by
[R-Solver](https://github.com/jatinchowdhury18/R-Solver) from a netlist. It is
derived circuit mathematics and was taken as-is rather than retyped. The knob
taper around it is this project's own work and differs from upstream — see
section 3c of `DESIGN.md` for why.
